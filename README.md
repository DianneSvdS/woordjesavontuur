# Woordjesavontuur

## Verbeterde PDF-import
De import gebruikt uitsluitend regels waarop tegelijk tekst in het linkervak en in het rechtervak staat. Zo wordt het begin van een kaartpaar herkend. Alleen de tekst rechts binnen dezelfde horizontale kaartband wordt aan de betekenis toegevoegd. Titels, paginanummers en losse tekst buiten de twee vakken worden genegeerd.

Alle herkende paren worden eerst in het controlescherm getoond. Woorden of betekenissen kunnen daar worden gecorrigeerd of verwijderd.

## Bewaren
Woordenlijsten worden automatisch in `localStorage` bewaard. Met **Backup opslaan** wordt een JSON-backup gedownload. Een JSON-backup kan via dezelfde importknop worden teruggezet.
